管理 Pi，不再往返文件和命令行。

Pi Switch 把常用的本地管理操作整理成一个稳定、可检查、可恢复的桌面工作区。

USAGE

用量统计

从本地 Session 汇总 Token、费用、请求、模型和 Provider 使用情况，不填充演示数字。

输入 / 输出 / 缓存 / 费用
MODELS

可视化模型配置

编辑 Provider、API 类型、密钥引用和模型参数。从 pi.dev 或 Provider 接口导入配置，保存前自动备份。

SESSIONS

历史 Session

搜索、阅读、重命名、删除和导出历史对话，也可以回到原目录继续会话。

SKILLS

Skill 管理

从本地目录安装 Skill，随时启用、停用或卸载。安装过程不会执行脚本。

BACKUP

安全写回

保留未知字段，写入模型配置前生成时间戳备份，并可运行 pi --list-models 校验。

LOCAL

数据留在本机

无需账户，不上传 Session，不使用云端数据库。自定义路径保存在本机 WebView。

查看安全边界 ↓

一个窗口，覆盖 Pi 的日常管理。

从模型到会话，从 Skill 到运行路径，关键操作保持在同一套信息结构中。

模型配置，从发现到写回。

从 Provider 拉取模型 ID，通过 pi.dev 匹配配置，最后在写入前检查每个字段。

配置和对话，默认留在你的电脑。

Pi Switch 直接读取 Pi 的本地目录，不建立账户，也不把 Session 同步到网络。

阅读安全说明 ↗
无云端数据库模型配置、Session 和 Skill 均由 Tauri 后端直接处理本地文件。
密钥引用优先推荐使用环境变量保存 API Key，界面默认隐藏已配置的明文密钥。
操作边界明确安装 Skill 只复制文件；删除 Session、卸载 Skill 等操作均需要确认。
